# Security Policy

## Supported versions

Only the latest release receives fixes. Please update before reporting.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: go to the **Security** tab of this
repository, then **Report a vulnerability**. Describe what you found and how to
reproduce it. Only the maintainer can see the report.

This is a one-person project, so replies may take a few days.

## What is in scope

lpm installs and exports `.zgp` / `.zgr` archives, which can come from other
people. Reports about an archive that can write outside its own folder, run
unexpected commands, or delete or copy files it should not touch are especially
welcome.
